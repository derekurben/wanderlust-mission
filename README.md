# Wanderlust Mission

The site behind wanderlustmission.com: a 3D map of Swiss Alpine Club hut trips, with each logbook told as a
scroll-driven story beside the map. Netlify publishes the `site/` folder on every push to `main`. There is no build step.

Live at https://wanderlustmission.com (Netlify project `wanderlust-mission`).

## Layout

| Path | What it is |
|---|---|
| `site/` | The published site. Open `site/index.html` locally to preview it. |
| `site/js/data.js` | Every trip: route, stats, hut pins, weather. Generated by `tools/make_data.py`. |
| `site/js/stories.js` | Every logbook's text and photos. Each block carries `f`, its position along the route from 0 to 1. Generated by `tools/make_story.py`. |
| `site/js/photos.js` | Sections and file names for the Photos page. |
| `site/img/log/` | Logbook photos. |
| `site/photos/` | Photos page: `thumb/` previews, `large/` 2,400 px views, `original/` full-resolution downloads (JPEG, quality 86). |
| `site/video/` | Logbook video clips (1080p MP4) and poster frames. |
| `source/` | Raw material the generators read: post text, routes, weather, photo manifest. |
| `tools/` | The generators. Run from anywhere: `python3 tools/make_data.py && python3 tools/make_story.py`. |
| `tools/device/` | One-off scripts used to prepare the Photos page on Derek's computer. Their folder paths are specific to that run. |

## Adding a logbook

1. Add the trip to the `L` list in `tools/make_data.py`: id, number, title, dates, canton, huts, and the route name.
2. Add the route to `source/` (GPX converted to `[lng, lat, elevation, time]` points) and the day's weather to `source/weather.txt`.
3. Add the text and photos to `source/posts.json`, the photo files to `site/img/log/`, and their entries to `source/manifest.json`.
4. Pin the story to the route in the `ANCHORS` table in `tools/make_story.py`. Anchors can be the start, the hut, the end,
   a fraction between two of those, or "the next time the route climbs through N metres". Unpinned blocks spread evenly between pins.
5. Run both generators, open `site/index.html` to check, commit and push. Netlify deploys the push.

Small edits (a typo, a caption, moving the hiker for one paragraph) can be made directly in `site/js/stories.js`,
but they are overwritten the next time the generators run, so make them in `source/` or the tools when possible.

## Known open items

- Four trip dates were guessed and drive the weather shown: Kröntenhütte, Albert-Heim-Hütte, Glattalphütte, Hundsteinhütte (`dateGuess` in `tools/make_data.py`).
- Story positions between anchors are estimates.
- The untouched camera originals are not in this repository; the Photos page offers full-resolution JPEG copies.

## Hut list and summit names

- `source/huts_master.json` is the master Google Sheet (name, height, done, date) with each hut's position, canton and commune from the swisstopo place-name search. `python3 tools/make_huts.py` turns it into `site/js/huts.js`.
- `source/peaks_raw.txt` is swisstopo's 1:200,000 name set around the visited huts, each with its class. The summits in it become `site/js/peaks.js`.

## Features added on 26 Nov 2026

| File | What it does |
|---|---|
| `site/js/sky.js` | Sun position for a date, time and place; the light, sky colour, cloud shadows, rain and snow drawn on the map |
| `site/js/app.js` | Also: the story clock (`buildClock`), fly-through, photo spots on the route, summit names, the look-around, unvisited huts, the mission replay |
| `site/js/pages.js` | Mission numbers and charts, the hut passport, the hut rankings |
| `site/js/rankings.js` | **Hut scores. Edit this file to rate a hut.** |
| `site/js/huts.js`, `site/js/peaks.js` | Generated: every hut on the list, and the summits around visited huts |

Times along a route come from the watch recording where there is one. Without it they are estimated from the length of the walk, and the clock on the map says "about".
